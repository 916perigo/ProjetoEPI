# 🚀 Configuração do Supabase (Fotos & Relatórios de EPI)

Siga os 3 passos simples abaixo no seu painel do Supabase ([https://supabase.com](https://supabase.com)):

---

### Passo 1: Obter as Chaves do Projeto
1. Acesse o seu projeto no **Supabase**.
2. Vá em **Project Settings** (ícone de engrenagem) > **API**.
3. Copie:
   - **Project URL** (ex: `https://abcdefghijkl.supabase.co`)
   - **anon public key** (chave pública do cliente)
4. Abra o arquivo [`api/front/js/supabaseClient.js`](file:///c:/xampp/htdocs/ProjetoEPI/ProjetoEPI/ProjetoEPI_Corrigido/api/front/js/supabaseClient.js) e cole nos campos indicados:
   ```javascript
   const SUPABASE_CONFIG = {
     url: "https://SEU_PROJETO.supabase.co", // cole sua URL aqui
     anonKey: "SUA_CHAVE_ANONIMA_AQUI",     // cole sua chave anon aqui
     bucketName: "fotos-verificacoes",
     tableName: "verificacoes"
   };
   ```

---

### Passo 2: Criar o Bucket no Storage para as Fotos
1. No menu lateral do Supabase, clique em **Storage**.
2. Clique no botão **New Bucket**.
3. Defina o nome como:
   ```
   fotos-verificacoes
   ```
4. **IMPORTANTE:** Marque a opção **Public Bucket** (para que o painel do administrador consiga carregar as fotos salvas).
5. Clique em **Save**.

---

### Passo 3: Criar a Tabela de Auditorias (SQL Editor)
No menu lateral do Supabase, vá em **SQL Editor**, crie uma **New Query**, cole o código abaixo e clique em **Run**:

```sql
-- Criação da tabela de auditorias e verificações de EPI
CREATE TABLE IF NOT EXISTS verificacoes (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    funcionario TEXT NOT NULL,
    email TEXT DEFAULT '-',
    status TEXT NOT NULL,
    detalhes TEXT,
    capacete_ok BOOLEAN DEFAULT FALSE,
    capacete_score INTEGER DEFAULT 0,
    colete_ok BOOLEAN DEFAULT FALSE,
    colete_score INTEGER DEFAULT 0,
    foto_url TEXT,
    data_hora TIMESTAMPTZ DEFAULT NOW(),
    created_at TIMESTAMPTZ DEFAULT NOW()
);

-- Ativa Row Level Security (RLS)
ALTER TABLE verificacoes ENABLE ROW LEVEL SECURITY;

-- Política para permitir inserção pública (da tela de verificação do operador)
CREATE POLICY "Permitir insercao anonima de verificacoes" 
ON verificacoes FOR INSERT 
TO anon 
WITH CHECK (true);

-- Política para permitir leitura pública (do painel admin)
CREATE POLICY "Permitir leitura anonima de verificacoes" 
ON verificacoes FOR SELECT 
TO anon 
USING (true);

-- Política pública para upload no bucket fotos-verificacoes
INSERT INTO storage.buckets (id, name, public) 
VALUES ('fotos-verificacoes', 'fotos-verificacoes', true)
ON CONFLICT (id) DO NOTHING;

CREATE POLICY "Permitir upload anonimo de fotos"
ON storage.objects FOR INSERT
TO anon
WITH CHECK (bucket_id = 'fotos-verificacoes');

CREATE POLICY "Permitir leitura de fotos do bucket"
ON storage.objects FOR SELECT
TO anon
USING (bucket_id = 'fotos-verificacoes');
```

---

Pronto! Assim que você colocar sua URL e Chave em `supabaseClient.js`, todas as novas verificações enviarão automaticamente as fotos e registros para a sua nuvem no Supabase, e o Administrador verá as fotos em tempo real no relatório!
